# HoneyMoon logo

The Moon drawn as a honeycomb. One cell near the south pole is filled with honey: the one site and date the search finds for you.

| Folder | What it is |
|---|---|
| `drip/` | Honey running out of the cell. For large uses: cover slide, poster, splash. |
| `nodrip/` | Plain honey cell. For small uses: favicon, app icon, header. |
| `source/make_logo.py` | Generates every SVG (`python3 make_logo.py`). Change colours or cell size here. |

Each folder has the same set, as SVG and transparent PNG:

| File | Use | PNG size |
|---|---|---|
| `honeymoon_mark` | Logo only, no background | 1024 × 1024 |
| `honeymoon_icon` | Logo on navy rounded square (app icon, favicon) | 1024 × 1024 |
| `honeymoon_lockup` | Logo + HONEYMOON, white text, for dark backgrounds | 2080 × 512 |
| `honeymoon_lockup_onlight` | Logo + HONEYMOON, navy text, for light backgrounds | 2080 × 512 |
| `honeymoon_lander_*` | Same set with lander legs under the Moon | same |

Below about 48 px use `nodrip` without legs; the drip and legs get too thin to read.

Colours: honey `#E0A238`, navy `#0E131B`, moon `#D9DCE0` → `#5B626C`, comb walls `#3A4049`.

Use of SI: drafted with Claude (Anthropic) and reviewed by Team ShabuShabu. No NASA or agency marks are used.
